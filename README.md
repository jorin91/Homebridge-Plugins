# Homebridge Plugins

This repository contains fully owned Homebridge plugins that are maintained together but installed one plugin at a time. Each plugin lives in its own folder and has its own README with configuration examples, install commands, update commands, and uninstall commands.

Releases are published per plugin so a Homebridge installation can install only the plugin it needs. Browse available package assets on the [GitHub Releases page](https://github.com/jorin91/Homebridge-Plugins/releases).

## Plugins

- [homebridge-jsg-scheduled-switch](homebridge-jsg-scheduled-switch/README.md): JSG Homebridge platform plugin for configurable scheduled virtual switches.
